# Посмотри в окно

Проектная работа Яндекс Практикума: вёрстка интерфейса приложения «Посмотри в окно» по макету в Figma.

Репозиторий: https://github.com/33mpty/posmotri-v-okno-ad

Приложение показывает видео из окон разных городов. Можно выбрать город и время суток, переключать ролики по карточкам и подгружать новые кнопкой «Показать ещё».

## Что сделано

- Лейаут страницы на флексах
- Стили текстов по макету, обрезка длинных заголовков и описаний
- Кастомные поле ввода и чекбоксы
- Состояния кнопок и карточек: `:hover`, `:active`, `:focus-visible`
- Позиционирование прелоадеров

## Технологии

- HTML
- CSS (Flexbox, `object-fit`, `line-clamp`, `:has()`)
